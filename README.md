# Walaiti Food QR – Digital Menu & Landing Page

> A premium QR-code landing page for **Walaiti Food** (Pizza & Café) — featuring the digital menu, both outlet locations, customer reviews, and social media links.

---

## 🔗 Sections

| Section | Description |
|---|---|
| **Menu** | Tabbed menu with categories – Pizza, Café, Sides |
| **Locations** | Both outlet addresses with maps links |
| **Reviews** | Customer testimonials and ratings |
| **Follow Us** | Instagram, Facebook & WhatsApp links |

## 📁 Project Structure

```
walaitifoodqr/
├── index.html    — Main landing page
├── style.css     — Premium dark-gold CSS design
├── app.js        — Menu rendering + interactivity
├── menu/         — (Coming soon) PDF menus for both locations
└── README.md
```

## 🚀 How to Use

1. Open `index.html` in any browser — no build step needed.
2. Scan the generated QR code to open the page on mobile.
3. Update `menuItems` array in `app.js` with real menu when ready.
4. Replace PDF link in `index.html` (`#menuPdfBtn`) with actual PDF URL.
5. Update phone numbers and social media handles with real ones.
